# Project Requirements Skill

Translate approved requirements into traceable proposed implementation tasks.

1. Read project context.
2. Read requirement.
3. Read relevant findings.
4. Read architecture decisions.
5. Identify dependencies.
6. Create tasks under `Documentation/Tasks/Proposed/`.
7. Define scope, out-of-scope, and acceptance criteria.
8. Do not approve tasks.

Respect project scope and glossary.
