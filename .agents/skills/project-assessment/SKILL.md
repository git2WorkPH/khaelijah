# Project Assessment Skill

Perform a read-only assessment against project context, requirements, architecture, and acceptance criteria.

Before assessment, read applicable `Documentation/Project/` files.

Deliver:
1. baseline summary;
2. requirement classification;
3. acceptance evidence;
4. stable findings;
5. existing-code disposition;
6. proposed task sequence;
7. risks and decisions required.

Do not modify code or approve tasks. A finding is not permission to implement.
