# Project Session Memory Skill

Maintain a compact durable project context so future AI sessions can resume without rereading the entire history or guessing repository state.

Update after major decisions, completed tasks, findings, requirement changes, architecture changes, important tests, blockers, commits, pushes, and merges.

Record:
- current phase;
- active requirement/task;
- recent decisions;
- open findings;
- completed/verified work;
- base branch and current branch;
- latest commit;
- working-tree state;
- verification state;
- remote-sync state when known;
- next exact action;
- files likely involved;
- files or areas that must not be modified;
- important constraints.

Session memory summarizes authoritative documents and never overrides approved requirements, architecture decisions, or tasks.
