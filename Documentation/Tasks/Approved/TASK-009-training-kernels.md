## Implementation and evidence
- `src/model/trainable/tokenizer.ts`: byte encoding, special tokens, lossless valid-Unicode round trips, replacement semantics for invalid generated bytes.
- `src/model/trainable/parameters.ts`: named owned arrays, seeded fan-in initialization, PRNG restore, gradient accumulation and clearing.
- `src/model/trainable/operations.ts`: rank-two row-major kernels with explicit local backward results. The future decoder owns composition/accumulation and frees kernel closures after backward.
- `test/training-kernels.test.ts`: finite differences for all floating-point inputs of each operation, shared embedding IDs, masked gradients, input snapshots, Unicode, deterministic parameter and RNG behavior, invalid shapes and IDs.
- Numerical thresholds: epsilon 1e-5, absolute error <=1e-6 or relative error <=1e-4. All checked entries pass. Full-model gradient checks await TASK-010.
- No training run or optimizer is included; no learned-model capability is claimed.
