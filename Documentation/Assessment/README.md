# Assessment

Assessment records what the AI discovers about the current repository.

## Rules
- Assessment is read-only unless explicitly requested otherwise.
- Findings use stable IDs.
- Findings map to requirements where possible.
- Facts, gaps, impact, and recommendations must be distinguished.
- Findings may propose tasks but do not approve them.

Store findings in `Documentation/Assessment/Findings/` and use `Documentation/Templates/FINDING-TEMPLATE.md`.
