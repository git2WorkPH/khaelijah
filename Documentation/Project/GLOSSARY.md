# Project Glossary

Use this document for domain-specific terminology.

| Term | Definition |
|---|---|
| Custom Transformer | The project's TypeScript implementation of a Transformer-based language-model architecture. |
| Knowledge layer | The independently managed corpus, metadata, indexes, refresh process, and retrieval APIs that provide current information at inference time. |
| Knowledge profile | A named, governed collection of sources, policies, indexes, and evaluation cases for a domain such as technology or medicine. |
| RAG | Retrieval-augmented generation: retrieving relevant corpus passages and placing them in the model's inference context. |
| Grounding | The degree to which a response is supported by retrieved evidence and accurately represents that evidence. |
| Provenance | Metadata identifying a retrieved item's source, version or publication date, ingestion time, licensing/access context, and retrieval time. |
| Application-building agent | A policy-bound workflow that turns a software request into research, planning, code, test, and review actions. |
| Vertical slice | The smallest end-to-end capability that crosses the required subsystems and can be evaluated by a user-facing outcome. |

Use these definitions consistently across requirements, architecture, tasks, code documentation, and session memory.
